# Search icon, SEO description, and app installation

## What will change
- Use the official Mene:Log symbol consistently for the browser favicon, search-result icon, Apple home-screen icon, and installed-app launcher icons.
- Add the favicon sizes and manifest details browsers and search engines expect, while keeping installation lightweight and online-only.
- Replace the homepage search description with clear, keyword-focused copy covering church management, membership, QR check-in, attendance, member care, branches, and reporting.
- Keep the homepage social description and the app manifest description aligned with the new wording.

## Validation
- Confirm each icon has valid square dimensions, accessible public URLs, and correct manifest declarations.
- Verify the homepage metadata and manifest in the rendered site on desktop and mobile.
- Check that the app remains error-free, then publish so search engines and install menus can receive the changes.

## Important expectation
Search engines choose when to recrawl and display a favicon, so the update can be made eligible immediately but may not appear in results until their next crawl.
